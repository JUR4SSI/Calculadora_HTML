# 🧮 Calculadora em JavaScript

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de uma calculadora utilizando **HTML, CSS e JavaScript**, com o objetivo de aplicar conceitos fundamentais de desenvolvimento web, manipulação de elementos HTML e lógica de programação.

A aplicação permite realizar operações matemáticas básicas por meio de uma interface simples e intuitiva, na qual o usuário pode interagir diretamente com os botões da calculadora.

## 🚀 Funcionalidades

A calculadora possui as seguintes funcionalidades:

- **Operações básicas:** adição, subtração, multiplicação e divisão.
- **Porcentagem:** permite calcular a porcentagem de um valor.
- **Raiz quadrada:** calcula a raiz quadrada de um número.
- **Alteração de sinal:** permite alternar entre números positivos e negativos.
- **Números decimais:** possibilita realizar operações com casas decimais.
- **Apagar último dígito:** remove o último número digitado.
- **Limpar visor:** reinicia a calculadora e apaga os valores armazenados.
- **Tratamento de erros:** identifica situações inválidas, como divisão por zero e raiz quadrada de números negativos.

## 🛠️ Tecnologias utilizadas

- **HTML5:** responsável pela estrutura e organização dos elementos da calculadora.
- **CSS3:** utilizado para estilização, organização dos botões e construção do layout.
- **JavaScript:** responsável pela lógica de funcionamento, execução das operações matemáticas e interação com os elementos da página.

## 💡 Justificativa da escolha da tecnologia

Para o desenvolvimento deste projeto, foi escolhido o **JavaScript Puro (Vanilla JavaScript)** em vez do framework Vue.js.

Essa escolha foi feita considerando a proposta e a complexidade da aplicação. Por se tratar de uma calculadora com funcionalidades relativamente simples, não existe a necessidade de utilizar um framework adicional para controlar a interface e seus componentes.

O JavaScript Puro permite realizar diretamente a manipulação do DOM, controlar os eventos dos botões, armazenar os valores das operações e atualizar o visor conforme a interação do usuário.

Além disso, essa abordagem apresenta algumas vantagens para o projeto:

- **Simplicidade:** evita a necessidade de instalar e configurar dependências adicionais.
- **Desempenho:** utiliza diretamente os recursos nativos do navegador, sem adicionar uma camada de abstração desnecessária.
- **Aprendizado:** permite praticar conceitos fundamentais de JavaScript, como funções, variáveis, estruturas condicionais, arrays e manipulação do DOM.
- **Facilidade de manutenção:** mantém a estrutura do projeto organizada e adequada ao seu tamanho.

Embora o Vue.js seja uma excelente opção para aplicações maiores, que exigem componentes reutilizáveis, gerenciamento de estados e interfaces mais dinâmicas, sua utilização neste caso não traria benefícios proporcionais à complexidade adicionada.

Portanto, o JavaScript Puro foi considerado a alternativa mais adequada para atender aos requisitos e objetivos deste projeto.

## ▶️ Como executar o projeto

Não é necessário instalar nenhuma dependência ou ferramenta adicional.

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `calculadora.html`.
4. Abra o arquivo em qualquer navegador atualizado.
5. Utilize os botões para realizar as operações matemáticas.

Também busca demonstrar a capacidade de escolher tecnologias adequadas às necessidades de uma aplicação, considerando fatores como simplicidade, desempenho, manutenção e objetivos de aprendizado.
